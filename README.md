# Система управления магазинами

Проект представляет собой систему управления магазинами, написанную на C++. Система позволяет:
- Управлять товарами в магазинах
- Совершать покупки
- Искать лучшие цены на товары в разных магазинах

## Структура проекта

- `Store.h` и `Store.cpp` - класс для управления магазином
- `Customer.h` и `Customer.cpp` - класс для управления покупателем
- `StoreManager.h` и `StoreManager.cpp` - класс для управления несколькими магазинами
- `main.cpp` - пример использования системы

## Компиляция

Для компиляции проекта используется компилятор g++ с поддержкой C++17:

```bash
g++ -std=c++17 main.cpp Store.cpp Customer.cpp StoreManager.cpp -o store_system
```

## Запуск

После компиляции запустите программу:

```bash
./store_system
```

## Пример использования

```cpp
// Создание магазина
Store store("SuperMarket");
store.addProduct("Milk", 2.5, 10);

// Создание покупателя
Customer customer("Alice", 50.0);
customer.addToShoppingList("Milk", 2);

// Совершение покупки
customer.purchaseItems(store);
```
